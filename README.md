# cloak

## این پروژه چیه

سه تا ابزارِ کوچیکِ به‌هم‌مرتبط که کمک می‌کنن اتصالِ HTTPSِ گوشیت (وقتی از یه VPN/پراکسی مثلِ v2rayNG استفاده می‌کنی) راحت‌تر از فیلترینگِ مبتنی‌بر-SNI رد بشه — بدونِ نیاز به روت کردنِ گوشی:

- **`cloak`** — پنهان‌سازیِ TLS handshakeِ واقعی پشتِ یه decoy handshakeِ جعلی.
- **`cloakscan`** — کشفِ خودکارِ IP/SNIِ زنده‌ی کلادفلر.
- **`cloaklinks`** — چک‌کردنِ لینک‌های کانفیگ (که از تلگرام/دوست می‌گیری) که کدوم‌هاشون واقعاً پشتِ کلادفلرن و با این روش سازگارن.

**یه نکته‌ی مهم و صادقانه:** من (کسی که این پروژه رو ساخته) برنامه‌نویسی یا شبکه بلد نیستم. این کل ماجرا از یه کنجکاوی شروع شد. این پروژه، از اولین خط کدش تا آخرین ویژگیش، **صفر تا صد با هوش مصنوعی (Claude)** ساخته شده. من فقط سؤال پرسیدم، ایده دادم، و تست کردم؛ خودِ کد، معماری، و تصمیم‌های فنی همه از طریق گفتگو با AI شکل گرفت.

---

## اسمش چرا «cloak»‌ـه

این ابزار واقعاً «جعل» (spoof) نمی‌کنه — چون spoof واقعی (جا زدن پکت جعلی روی همون اتصال واقعی) فقط با دسترسی روت ممکنه. کاری که این ابزار می‌کنه چیز دیگه‌ایه: اتصال واقعی رو **پنهان** می‌کنه پشت یه اتصال جعلیِ بی‌خطر که زودتر می‌میره. کلمه‌ی انگلیسیِ دقیق برای «پنهان کردن زیر یه پوشش» میشه **cloak**.

## نصبِ سریع (پیشنهادی)

```bash
curl -fsSL https://raw.githubusercontent.com/SPARKY-CR/Cloak/main/install.sh | bash
```

این یه‌خط خودکار معماریِ گوشیت رو تشخیص میده، باینریِ آماده‌ی متناظرو از آخرین Release دانلود می‌کنه، و توی `~/cloak/` نصب می‌کنه. اگه معماریت شناخته‌نشده بود، خودش از سورس با `gcc` می‌سازتش.

## نصبِ دستی (جایگزین)

از صفحه‌ی [Releases](../../releases)، زیپِ متناظر با گوشیت رو دانلود کن:

| فایل | برای |
|---|---|
| `cloak-arm64-v8a.zip` | اکثرِ گوشی‌های اندرویدیِ چندسالِ اخیر |
| `cloak-armeabi-v7a.zip` | گوشی‌های قدیمی‌ترِ ۳۲بیتی |
| `cloak-x86_64.zip` | کامپیوترِ لینوکس/WSL |

اکسترکتش کن، بعد:
```bash
chmod +x cloak cloakscan cloaklinks
./cloak
```

## ساختن از سورس (اگه ترجیح میدی خودت کامپایل کنی)

```bash
pkg install clang    # روی Termux
gcc -O2 -Wall -o cloak cloak.c -lpthread
gcc -O2 -Wall -o cloakscan cloakscan.c -lpthread
gcc -O2 -Wall -o cloaklinks cloaklinks.c -lpthread
```

## ابزارِ اول: `cloak`

TLS ClientHelloِ واقعی رو پشتِ یه decoy handshakeِ جعلی (با SNIِ مجاز و TTLِ پایین) پنهان می‌کنه.

```bash
./cloak                 # اولین اجرا: cloak.conf رو می‌سازه و خارج میشه
nano cloak.conf          # تنظیمات رو ویرایش کن
./cloak
```

راهنمای کاملِ تنظیمات: [`cloak-guide.md`](cloak-guide.md)

## ابزارِ دوم: `cloakscan`

رنجِ IPِ کلادفلر رو نمونه‌برداری می‌کنه، ترکیب‌های IP+SNIِ زنده رو پیدا می‌کنه، و خودکار `cloak.conf` رو آپدیت می‌کنه.

```bash
./cloakscan
```

## ابزارِ سوم: `cloaklinks`

لینک‌های VLESS/Trojan/VMess رو می‌گیره، چک می‌کنه کدوم‌هاشون از نظرِ پروتکل سازگارن (نه Reality، نه بدونِ TLS)، و کدوم‌هاشون واقعاً روی IPِ کلادفلر هستن — بعد آدرسِ سازگارها رو به `127.0.0.1:PORT` بازنویسی می‌کنه.

```bash
./cloaklinks             # اولین اجرا: cloaklinks.conf رو می‌سازه
nano links.txt            # لینک‌هاتو پیست کن
./cloaklinks
```

## محدودیت‌ها (صادقانه)

- این جایگزینِ کاملِ اسپوفِ سطح‌روت نیست.
- اثربخشیش به شرایط شبکه‌ی هر شخص بستگی داره.
- نتیجه‌ی `cloakscan`/`cloaklinks` فقط یه «عکسِ لحظه‌ای»ه — چیزی که الان کار می‌کنه ممکنه فردا عوض بشه.
- این پروژه رو یه فرد کنجکاو با کمک AI ساخته، نه یه تیم امنیتی حرفه‌ای.
